eBay Copy Assistant Privacy Policy

Last updated: September 7, 2026.

eBay Copy Assistant processes listing data only after the user clicks Ask Gemini. It has no developer-operated backend, analytics, advertising, or data-sale functionality.

Data processed

The extension reads the current eBay listing URL, title, price, condition, shipping, returns, seller information, visible reviews, item specifics, and description to provide its user-facing analysis feature. If the user chooses them, it also reads up to ten images from the listing's main gallery.

How data is used and shared

The prompt is generated locally, copied to the clipboard as a fallback, and inserted into the Google Gemini page selected by the user. Chosen gallery images are fetched over HTTPS from eBay's image CDN and inserted into the selected Gemini page as separate files. Google Gemini is the only external recipient; its processing is governed by Google's terms and privacy policy.

Storage and retention

Pending prompts are temporarily stored in chrome.storage.session for five minutes starting when the Gemini tab is opened. After text insertion, the prepared request can remain for up to thirty minutes while selected images are transferred. Image bytes are held only in temporary service-worker memory and are not written to Chrome Sync or session storage. Expired requests and temporary image data are removed automatically or when next read. Settings and saved Gemini report URLs use Chrome Sync. The extension does not store listing prompts or image bytes on developer servers.

Deletion

Pending prompts expire automatically. Users can remove saved extension data through Chrome's extension data controls. Uninstalling the extension stops further processing; synced data may remain in the user's Google account until cleared through Chrome.

Limited Use

The use of information received from browser APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's disclosed single purpose.
