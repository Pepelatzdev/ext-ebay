# eBay Copy Assistant

eBay Copy Assistant — це розширення для браузера Google Chrome, яке допомагає швидко копіювати вичерпну інформацію про товари з eBay та отримувати AI-аналіз через Google Gemini.

## Функціонал

- **Визначення типу лістингу:** Розширення автоматично визначає аукціон, фіксовану ціну (Buy It Now) чи аукціон із можливістю швидкої покупки.
- **Комплексний парсинг:** Збирає ціну (Bid / Buy It Now), доставку, повернення, стан (Condition), повний опис, усі характеристики (Item Specifics).
- **Аналіз продавця:** Збирає ім'я, рейтинг та останні відгуки покупців (Seller Reviews).
- **Ask Gemini:** Відкриває налаштований Gemini Gem, автоматично вставляє зібрані дані товару та очікує на згенерований звіт.
- **Gemini Report Ready:** Після генерації звіту на сторінці товару з'являється картка з прямим посиланням на чат Gemini.
- **Крос-девайс синхронізація:** URL-адреси звітів Gemini зберігаються через `chrome.storage.sync` (FIFO, ліміт 400 записів) та доступні на всіх пристроях.
- **Нативна інтеграція:** Кнопки розширення органічно вбудовуються під кнопкою «Add to Watchlist» у стилі eBay.

## Встановлення

### Варіант 1: Unpacked (для розробки)

1. Завантажте або клонуйте цей репозиторій.
2. Відкрийте `chrome://extensions/` і увімкніть **Developer mode**.
3. Натисніть **Load unpacked** і виберіть папку проєкту.

### Варіант 2: CRX з авто-оновленням

1. Завантажте `extension.crx` зі [сторінки GitHub Pages](https://pepelatzdev.github.io/ext-ebay/).
2. Відкрийте `chrome://extensions/` і перетягніть файл `.crx` у вікно браузера.
3. Оновлення відбуватимуться автоматично через `update.xml`.

## Використання

1. Відкрийте сторінку будь-якого товару на `ebay.com` (або іншому регіональному домені eBay).
2. Під кнопкою «Add to Watchlist» знайдіть кнопки розширення:
   - **Copy Assistant** — копіює зібрані дані у буфер обміну.
   - **Ask Gemini** — відкриває Gemini Gem та автоматично вставляє дані для аналізу.
3. Після генерації звіту Gemini на сторінці товару з'явиться картка **Gemini Report Ready** з посиланням **View Report**.

## Налаштування

Натисніть правою кнопкою на іконку розширення → **Options**, або відкрийте сторінку налаштувань через `chrome://extensions/`:

- **Prompt Preamble** — текст-преамбула, що додається перед даними товару (наприклад: *«Проаналізуй цей товар на eBay та підкажи, чи це вигідна угода:»*).
- **Gemini Gem URL** — URL власного Gemini Gem, який відкриватиметься при натисканні «Ask Gemini».

## Технічні деталі

- **Manifest V3** з модульною архітектурою:
  - `config.js` — спільні константи та CSS-селектори eBay
  - `extractors.js` — парсинг DOM та форматування промпту
  - `ui.js` — рендеринг кнопок, стани фідбеку, картка «Report Ready»
  - `content.js` — точка входу та оркестрація
  - `gemini-content.js` — авто-вставка промпту в Gemini, моніторинг URL чату
  - `background.js` — service worker (CORS-проксі, відкриття вкладок)
  - `options.js` / `options.html` / `options.css` — сторінка налаштувань
- **chrome.storage.sync** для крос-девайс синхронізації URL звітів.
- **CI/CD:** GitHub Actions автоматично збирає, підписує `.crx` і деплоїть на GitHub Pages із `update.xml` для авто-оновлень.
- Підтримка регіональних доменів: `.com`, `.co.uk`, `.de`, `.fr`, `.it`, `.es`, `.com.au`, `.ca`, `.at`, `.pl`.
