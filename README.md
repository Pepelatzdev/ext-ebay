# eBay Copy Assistant

eBay Copy Assistant — це розширення для браузера Google Chrome, яке допомагає швидко та зручно копіювати вичерпну інформацію про товари з сайту eBay для подальшого аналізу. 

## Функціонал
- **Визначення типу лістингу:** Розширення автоматично визначає, чи це аукціон, лістинг фіксованої ціни (Buy It Now), чи аукціон з можливістю швидкої покупки. 
- **Комплексний парсинг:** Збирає поточну ціну (Bid) та/або ціну Buy It Now, інформацію про доставку, повернення товару, загальний стан (Condition), повний опис товару, а також усі детальні характеристики (Item Specifics).
- **Аналіз продавця:** Збирає ім'я продавця, загальний відсоток рейтингу та копіює останні відгуки покупців (Seller Reviews).
- **Нативна інтеграція:** Кнопка розширення органічно вбудовується під нативною кнопкою «Add to Watchlist» та відповідає офіційному дизайну елементів eBay.

## Встановлення

Оскільки це розширення не поширюється через Chrome Web Store, його потрібно встановити як "unpacked" (розпаковане):
1. Завантажте цей репозиторій до себе на комп'ютер.
2. Відкрийте браузер Chrome і перейдіть на сторінку розширень: `chrome://extensions/`.
3. Увімкніть **Developer mode** (Режим розробника) у правому верхньому куті сторінки.
4. Натисніть кнопку **Load unpacked** (Завантажити розпаковане розширення) і виберіть папку, куди ви зберегли цей проект.
5. Розширення встановлено! Воно автоматично працюватиме на сторінках товарів eBay.

## Використання
1. Відкрийте сторінку будь-якого товару на сайті `ebay.com`.
2. У правій частині сайту під кнопкою «Add to Watchlist» знайдіть нову кнопку **Copy Assistant**.
3. Натисніть її. Увесь зібраний текст (сформатований у зручному для читання або для AI-ботів вигляді) буде автоматично скопійовано у ваш буфер обміну. 
4. Текст матиме преамбулу за замовчуванням (яку можна змінити в налаштуваннях розширення), після якої йтимуть усі характеристики товару.

## Налаштування
Ви можете змінити стартовий текст-звернення (преамбулу), що додається до початку скопійованого тексту. Для цього:
- Натисніть на іконку розширення на панелі інструментів Chrome.
- Введіть свій текст, наприклад: *"Проаналізуй цей товар на eBay та підкажи, чи це вигідна угода:"*
- Натисніть "Save".

## Технічні деталі
Розширення написано з використанням Manifest V3. Воно використовує Content Scripts (`content.js`, `content.css`) для взаємодії зі сторінкою, витягування інформації та ін'єкції кнопки, `options.js` для сторінки налаштувань та `background.js` для обробки CORS-запитів iframe (для витягування опису товару).
